# Support

For usage questions and feature ideas, open a GitHub Discussion. For
reproducible bugs, open an issue and include your macOS version, app version,
expected behavior, and steps to reproduce.

Never post access tokens, API keys, WHOOP exports, database files, or
screenshots containing personal health information. Reproduce UI issues with
the `WhoopScope Demo` scheme whenever possible.

Security issues belong in a private vulnerability report, as described in
[SECURITY.md](SECURITY.md).
