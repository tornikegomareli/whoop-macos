WhoopScope’s first public alpha brings a private, native dashboard for the data
available through the official WHOOP Developer API.

## Included

- Complete local sync for profile, body measurements, cycles, recovery, sleep,
  and workouts.
- Today dashboard, historical trends, and detailed explorers.
- Menu-bar summary and desktop widgets.
- Siri, Shortcuts, and Spotlight actions.
- Grounded data chat with Apple’s on-device model or an OpenAI key you provide.
- Optional direct iPhone-to-Mac Apple Health enrichment that excludes sleep.
- A privacy-safe synthetic demo mode.

## Early-access limits

WHOOP sign-in is subject to the Developer Platform’s pre-approval member
allowance until the shared WhoopScope application receives broader approval.
The project and synthetic demo remain available to everyone.

This is prerelease software. Back up important data, report bugs using
synthetic examples, and never attach health records or credentials to a public
issue.
